DuitRia Board Game.

The objective of the "DuitRia" game project is for players, up to a maximum of 4, to accumulate wealth by engaging in property transactions. The game can be played offline with 
multiplayer functionality, and each player receives an initial deposit of RM 15M from the Creator. The player with the highest total from a dice throw goes first, and turns proceed 
accordingly. Players start on the "GO" corner, throw the dice, and move accordingly. Depending on the landed space, players can buy properties, pay rent, handle taxes, draw 
cards, or face various in-game events. Multiple players can occupy the same space simultaneously. The goal is to strategically navigate the board, make property-related 
decisions, and become the wealthiest player.
